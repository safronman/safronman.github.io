# Контакт — shape

## Цель

Завершить портфолио понятным и быстрым действием для HR или руководителя: написать в Telegram или email.

## Роль в странице

Светлый блок `Clear Surface` после тёмного «Технического голоса для маркетинга». Он создаёт спокойное завершение страницы и переводит просмотр работ в разговор.

## Текст

### Заголовок

**Открыт к новым задачам и командам**

### Вводный текст

Если вам нужен специалист, который совмещает frontend-экспертизу, обучение и техническую коммуникацию — буду рад обсудить задачу.

## Контакты

1. **Telegram** — `@safronman`, основное действие: «Написать в Telegram».
2. **Email** — `safronmanbox@gmail.com`, ссылка `mailto:`.
3. **GitHub** — `@safronman`, внешняя ссылка на профиль.

## Компоновка

- Слева — крупный заголовок и вводный текст.
- Справа — компактный перечень из трёх контактов с тонкими линиями.
- Telegram выделяется единственной синей кнопкой; email и GitHub остаются текстовыми ссылками.
- На мобильных устройствах сначала идут заголовок и текст, затем контакты одной колонкой.

## Визуальная система

- Фон — `Clear Surface` (`#F7F7FA`), текст — `Studio Ink` (`#17141D`).
- Signal Blue используется только для кнопки Telegram и focus-visible.
- Без фотографии, карточек и формы обратной связи.
- Генерация изображений не используется по правилам проекта.

## Поведение

- Telegram и GitHub открываются в новой вкладке.
- Email открывает почтовый клиент через `mailto:`.
- Все интерактивные элементы имеют видимое клавиатурное состояние.
