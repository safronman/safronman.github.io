# Методическое пособие — shape

## Цель

Показать HR один глубокий, доступный без регистрации рабочий артефакт: React Style Guide. Блок подтверждает, что автор создаёт не только уроки, но и стандарты, по которым студенты и команда разработки пишут единообразный код.

## Основное действие

Открыть руководство `https://code-style.it-incubator.io/react` в новой вкладке. Скриншот и текстовая ссылка «Открыть руководство ↗» ведут к одному адресу.

## Ключевое сообщение

Заголовок: «Методическое пособие».

Пособие фиксирует общие правила написания кода, чтобы решения о нейминге, структуре компонентов, типах, форматировании и коммитах не оставались личными предпочтениями каждого разработчика. Team lead может ссылаться на руководство во время code review, а студенты и разработчики получают единый ориентир для работы в проекте.

## Визуальное направление

- Светлая нейтральная поверхность `#F7F7FA` создаёт паузу после тёмного блока презентаций.
- Рабочий документ, а не рекламная карточка: плоские поверхности, тонкие разделители, без теней и дополнительной декоративной графики.
- Скриншот руководства — главный визуальный аргумент. Он показывает навигацию, поиск, правила и фрагменты кода.
- Генерация изображений запрещена правилами проекта; используется предоставленный ассет `public/manual/manual-react-style-guide.png`.

## Компоновка

- Заголовок без дополнительного поясняющего текста.
- Ниже — одна крупная двухколоночная композиция: слева кликабельный скриншот руководства, справа краткое описание, три строки с тонкими разделителями и внешняя ссылка.
- Три строки с иконками Lucide React: `Braces` — «Единый стиль кода», `UsersRound` — «Понятный ориентир для команды», `MessageSquareCheck` — «Основание для code review».
- На мобильном: текст → скриншот → ссылка.

## Состояния и доступность

- Скриншот — семантическая ссылка с точным `aria-label`.
- Внешняя ссылка открывается в новой вкладке и имеет видимый маркер `↗`.
- Hover: сдержанное затемнение скриншота без изменения компоновки.
- Keyboard: `focus-visible` с контуром Signal Blue.
- Для `prefers-reduced-motion` отключаются анимации затемнения и масштабирования.
