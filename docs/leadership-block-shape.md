# Блок «Руководитель направления»

Статус: подтверждён для реализации.

## Задача

До показа кейсов быстро объяснить HR-менеджеру, что автор портфолио способен отвечать не только за отдельные материалы, но и за образовательное направление: людей, качество, программу и практику.

## Содержание

- Заголовок: «Руководитель направления, который остаётся в контакте с учебным процессом».
- Вводный текст: «Управляю преподавателями, утверждаю программы и стандарты, провожу code review и создаю ключевые учебные артефакты».
- Четыре зоны ответственности:
  - Программы, домашние задания и экзамены.
  - Обучающие видео и вебинары.
  - Презентации и методические материалы.
  - Стандарты качества и code review.

Не использовать размер команды, количество программ и другие непубличные или слабопоказательные метрики. Название компании не является частью основного текста блока; оно допустимо только там, где необходимо для описания конкретного публичного проекта.

## Визуальное направление

- Полноширинная фиолетовая поверхность — осознанный единичный акцент в системе «ночная студия».
- Крупное утверждение слева; справа — вводный абзац и строгий список с тонкими разделителями.
- Без фотографии, CTA, карточек, градиентов, свечения и декоративных маркеров.
- На мобильном: заголовок, затем вводный текст и список в одну колонку.

## Рамки реализации

Production-ready, адаптивный, статичный блок с контрастом не ниже WCAG AA. Его задача — дать контекст масштаба ответственности, не отвлекая от следующих за ним работ.
