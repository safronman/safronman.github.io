# Техническая основа — shape

## Цель

Дать HR короткое и проверяемое основание доверять преподаванию технических тем. Это не CV и не шкала навыков, а контекст: автор глубоко работает с frontend-разработкой и связывает её с качеством интерфейсов, инженерными практиками и современными AI-инструментами.

## Роль в странице

Светлый блок `Clear Surface` после тёмного блока «Как проходит обучение». Он возвращает страницу к спокойному чтению и дополняет уже показанные результаты техническим контекстом.

## Компоновка

- Крупный заголовок и короткий тезис расположены сверху слева.
- Ниже — вертикальный перечень из четырёх направлений с тонкими разделителями.
- Frontend — главное направление: оно визуально крупнее и содержит больше конкретики.
- UI-системы, инженерные практики и AI — равные компактные строки, которые расширяют контекст.
- На мобильных устройствах всё выстраивается в одну колонку.

## Текст

### Заголовок

**Техническая основа**

### Тезис

Глубоко работаю с frontend-разработкой и связываю её с качеством интерфейсов, инженерными практиками и AI-инструментами.

### Направления

1. **Frontend** — JavaScript, TypeScript, React, Redux Toolkit, RTK Query, React Router, React Hook Form и Zod.
2. **UI и дизайн-системы** — Storybook, Radix UI, UI-kit, accessibility, CSS-архитектура и компонентный подход.
3. **Инженерные практики** — Git и GitHub, REST и WebSocket, тестирование, code review и архитектура приложений.
4. **AI в разработке** — Codex, MCP, Context7, Playwright, RAG и Agent Skills; применяю инструменты в материалах и ежедневной разработке.

## Визуальная система

- Фон — `Clear Surface` (`#F7F7FA`), основной текст — `Studio Ink` (`#17141D`).
- Mineral Teal используется только как небольшой ориентир: иконка или маркер у направлений.
- Тонкие разделители формируют структуру; карточки, логотипы, прогресс-бары, уровни навыков и диаграммы не используются.
- Изображения не нужны. Генерация изображений не применяется по правилам проекта.

## Поведение

- Блок статичный: без карусели, анимации или скрытого содержания.
- Возможные ссылки на материалы добавляются позже только как текстовые действия рядом с конкретным направлением.
