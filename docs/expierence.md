- [часть 1 — Application Setup, Queries, Mutations, Re-fetching & Code Splitting](https://youtu.be/5qtCsfMytuk?si=O7IYG7XUOYBwEs9e)

📝 Курс посвящён глубокому изучению RTK Query на практике — от базовой настройки до продвинутых
сценариев работы с API в React-приложениях. Вы научитесь создавать полноценный frontend с
авторизацией, CRUD-операциями, загрузкой изображений, пагинацией, infinite scroll,
websocket-обновлениями и системой кэширования. В программе подробно разбираются RTK Query, Redux
Toolkit, TypeScript, Zod, React Hook Form, Socket.io и современные подходы к обработке ошибок и
оптимистичным обновлениям. Курс подойдёт разработчикам, которые хотят уверенно использовать RTK
Query в реальных production-проектах.

**Программа интенсива Что ты будешь делать в течение 5 дней:**

- **Первый день:** научишься создавать приложения на React, удалишь шаблонный код и установишь
  сторонние библиотеки. Задашь базовую структуру нашему приложению, познакомишься с такими понятиями
  как компонент и JSX и научишься работать с изображениями.

- **Второй день:** научишься настраивать роутинг и разберешься с базовой навигацией. Разберешься с
  модульным CSS и научишься работать с CSS переменными.

- **Третий день:** научишься взаимодействовать с сервером, отрисуешь персонажей при помощи метода
  map, разберешь хуки useState и useEffect

- **Четвертый день:** реализуешь пагинацию, научишься блокировать кнопки и отрефакторишь полученный
  результат, чтобы избавиться от дублирования. Реализуешь поиск и научишься обрабатывать ошибки.

- **Пятый день:** разработаешь страницу персонажа, узнаешь, что такое динамический роутинг,
  реализуешь кнопку go back и задашь статус каждому персонажу.

разработки.

## Автор style guide по React

- [style guide React](https://code-style.it-incubator.io/react)

Документ представляет собой подробное руководство по написанию чистого, единообразного и
масштабируемого кода на React и TypeScript. В нём собраны правила нейминга, организации структуры
проекта, оформления импортов, работы с типами, enum, комментариями, pull request и соглашениями по
коммитам. Также подробно разбирается настройка рабочего окружения: ESLint, Prettier, Stylelint,
aliases, конфигурация Vite и WebStorm для комфортной разработки. Отдельное внимание уделено
архитектуре feature-based проектов, читаемости кода и единым стандартам командной разработки.
Руководство основано на практиках Google, TypeScript-документации и подходах популярных open-source
проектов вроде React, Redux Toolkit и TanStack Query.
